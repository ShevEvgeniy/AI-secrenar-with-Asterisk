# Handoff Archive

This directory stores sanitized long-form handoffs for node work.

Handoff files may include command plans, read-only findings, GO/NO-GO notes, and validation summaries. They must not include real secrets, tokens, private keys, raw secret env output, transcript text, large logs, audio, binary artifacts, or unredacted sensitive evidence.

Keep short operational playbooks and external coordination notes concise. Use this repo archive as the durable long-form handoff source.
