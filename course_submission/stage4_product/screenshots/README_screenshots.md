# Скриншоты и видео

Координатору необходимо подготовить:

1. Форму в браузере до ввода или с очищенным полем.
2. Заполненную форму с синтетическим обращением и выбранным типом.
3. Результат: извлечённые поля, ответ клиенту, карточка менеджера, фрагменты базы, TTS-текст и видимый путь сохранения.
4. При необходимости — локальный `runtime/processed_appeals.jsonl` с одной синтетической записью.
5. Опциональный GPT-режим снимать только при локально заданном ключе; ключ, терминал с окружением и заголовки запроса не показывать.

Для короткого видео последовательно показать запуск команды, открытие `http://127.0.0.1:8000/`, отправку формы и прокрутку полного результата.
