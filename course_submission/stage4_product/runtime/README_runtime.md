# Runtime

`processed_appeals.jsonl` создаётся автоматически при обработке обращения. Одна строка — один полный результат в JSON. Используйте только синтетические данные; не добавляйте реальные клиентские обращения.

Для проверки структуры запустите `python course_submission/stage4_product/app.py --sample-smoke`.
