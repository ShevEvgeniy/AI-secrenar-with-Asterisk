# Локальный продукт «Нейро-секретарь Анна»

## Что добавлено

Stage 4 переработан из набора модулей и консольной демонстрации в готовый локальный MVP. Рецензент открывает страницу в браузере, вводит расшифровку звонка, текстовое сообщение или email и сразу видит результат обработки. Приложение использует только стандартную библиотеку Python и по умолчанию не требует API-ключа.

## Архитектура front → back → result

1. **Front:** браузерная форма принимает тип, текст и необязательную метку источника.
2. **Back:** `pipeline.py` извлекает имя, город, телефон, ИНН, намерение и тип обращения; загружает локальную базу знаний; выбирает три релевантных фрагмента; формирует ответы.
3. **Result:** страница показывает поля, фрагменты базы, ответ клиенту, карточку менеджера, TTS-ready текст и путь сохранения. Полный результат добавляется в `runtime/processed_appeals.jsonl`.

## Запуск

Из корня репозитория:

```powershell
python course_submission/stage4_product/app.py
```

Открыть <http://127.0.0.1:8000/>. В форме уже находится синтетический пример; достаточно нажать «Обработать обращение». Автоматическая проверка без браузера:

```powershell
python course_submission/stage4_product/app.py --sample-smoke
```

## Сценарии для проверки

**Расшифровка звонка — поставка:**

> Здравствуйте, меня зовут Иван. Я из Казани. Хочу уточнить сроки поставки оборудования. Телефон 8 903 678 46 53. ИНН 7701234567.

**Email — оплата и документы:**

> Добрый день! Меня зовут Ольга, компания из Самары. Подскажите, как получить счёт и закрывающие документы после оплаты? ИНН 6312345678. Ответ прошу направить на корпоративную почту.

**Текстовое сообщение — гарантия и сервис:**

> Я Алексей из Тулы. Оборудование перестало работать. Подскажите срок гарантии и как оформить обращение в сервис. Телефон +7 910 555 12 34.

## Сохранённые файлы и материалы сдачи

Каждая обработка добавляет одну JSON-строку в `runtime/processed_appeals.jsonl`; файл содержит вход, извлечённые поля и все результаты. В репозитории допустим только синтетический пример. Инструкции по кадрам находятся в `screenshots/README_screenshots.md`.

Для видео следует показать запуск, заполненную форму, нажатие кнопки, полный блок результата и появившуюся строку JSONL. Секреты и содержимое окружения показывать нельзя.

## Границы ревизии и GPT

Asterisk, Gateway, SSH и серверная инфраструктура не входят в эту учебную ревизию: цель — доказать целостный продуктовый путь обработки входящего обращения локально и безопасно. Приложение не обращается к телефонии или внешним сервисам.

Опциональный GPT-режим является отдельным возможным расширением и не включён в основной путь. Его можно реализовать только при явном включении пользователем и наличии локального `OPENAI_API_KEY`; ключ нельзя добавлять в код, логи или материалы сдачи.
