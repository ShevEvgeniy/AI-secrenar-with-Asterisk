# Stage 4 Screenshot Guide

Capture screenshots or a short video that shows the reviewer the final neuro-employee flow.

Recommended screenshots:

1. Terminal before running `python course_submission/stage4/final_demo.py`.
2. The entered client message.
3. The final output with extracted fields, selected knowledge chunks, secretary answer, and TTS-ready text.
4. Optional: real GPT/OpenAI response screenshot if the coordinator separately runs an optional API-backed demo.
5. Optional: GitHub repository page or final Drive/Yandex/Google submission folder.

Do not include API keys, tokens, Authorization headers, private environment dumps, server logs, or real customer data in screenshots.
